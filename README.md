## The idea

College information is everywhere — assignment dates in one place, event announcements somewhere else, notes buried in chats, and lost items travelling by word of mouth.

**CampusMate brings these everyday student needs into one shared space.**

It's designed around the things students actually do between lectures, deadlines and campus life.

## More than a list of pages

A few details make CampusMate feel like a campus companion:

- **Campus-inspired landing page** — photo carousel, campus spaces and a student survival guide.
- **Sliding sign-in experience** — switch between sign-in and registration with a split-panel transition.
- **Attendance check** — calculate your attendance against the 75% target.
- **One search, multiple places** — look across assignments, events, listings and study resources.
- **Light & dark themes** — switch the look to suit your preference.

## Get it running

Want to explore the project locally? You'll need [Node.js](https://nodejs.org/) and npm.

### 1. Clone the repository

```bash
git clone https://github.com/nishantp0229/CampusMate-V2.git
cd CampusMate-V2
```

### 2. Install packages

```bash
npm install
```

### 3. Start the app

```bash
npm run dev
```

Open the local address printed in your terminal — usually `http://localhost:5173`.

### Handy commands

| Command | What it does |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Build the app for production |
| `npm run preview` | Preview the production build |
| `npm run lint` | Check the code with Oxlint |

## Project status

CampusMate is currently a **frontend project with demo data and local UI state**. You can explore its main flows without setting up a database.

Supabase integration is planned; the presence of setup files does not mean live authentication or database features are already connected.
